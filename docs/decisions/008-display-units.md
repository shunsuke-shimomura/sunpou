# ADR-008: Display での SI 単位文字列表示

## 判断内容

`Scalar<D, P>` の `Display` impl で値の後に SI プレフィクス記号と
次元文字列を表示する。例: `"7 km"`, `"9.8 m·s⁻²"`, `"42"` (無次元)。

## 背景

従来の Display は値のみを表示していた (`"7"`)。デバッグ時に単位が
分からないため、ユーザーが手動でコメントを付ける必要があった。

## 設計

### DimName trait

`Dim<L, M, T, I, Th, N, J>` の各指数を `Integer::to_i64()` で取得し、
非ゼロの指数のみ SI 基本単位記号で表示する。

```
Length: "m"
Velocity: "m·s⁻¹"
Force: "m·kg·s⁻²"
Dimensionless: "" (空文字)
```

### PrefixName trait

プレフィクスの記号を返す。`Z0 → ""`, `P3 → "k"`, `N9 → "n"`, etc.

### 固定サイズバッファ

`no_std` 対応のため、ヒープ割り当てなしの固定サイズバッファ (64 bytes)
で文字列を構築する。

## 選択肢

### A. SI 単位記号で表示 (採用)

`"7 km"`, `"980 m·kg·s⁻²"`

- **Pros**: 正確。曖昧さがない。
- **Cons**: Force が `"m·kg·s⁻²"` で `"N"` ではない。

### B. 派生単位名 (N, J, Pa 等) で表示

`"980 N"`, `"100 J"`

- **Pros**: 読みやすい。
- **Cons**: 次元から派生単位名への逆引きテーブルが必要。複合単位の表現が曖昧。

### C. 値のみ (従来)

- **Cons**: 単位情報なし。

## 結論

A を採用。基本単位記号は一意で正確。派生単位名サポートは将来の拡張として検討可能
（ユーザーが独自の Display wrapper を作ることも容易）。
